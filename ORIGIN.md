# Source history

The IOP software in this repository is derived from [AI4Instruments](https://github.com/Cherish0925/AI4Instruments) at commit `f5039f211fd0cec93a5394e5641dac4a0a72b0fc` (IOP Runtime 0.8.5). Its original commit history, research papers, ecosystem survey and laboratory comparison remain there.

This repository contains the independently released IOP product. Python imports (`ai4instruments.iop`), the `iop` command, the TypeScript package name and existing data locations are retained so that established laboratory programs continue to work. New installations and releases use this repository.
